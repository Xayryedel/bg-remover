# PhotoLab 🎨✨

Быстрый и удобный веб-редактор изображений, который работает прямо в браузере. Главная фишка — **удаление фона с помощью нейросети без отправки фото на сервер**.

## 🚀 Возможности

- **Удаление фона**: использует библиотеку `@imgly/background-removal`, которая работает на WebAssembly (нейросеть загружается прямо в браузер).
- **Ретушь**: регулировка яркости, контрастности, насыщенности и размытия в реальном времени.
- **Скачивание**: сохранение результата в формате PNG (с прозрачным фоном).
- **Приватность**: все манипуляции с изображением происходят локально на твоем устройстве. Никаких загрузок на сторонние серверы.
- **Адаптивность**: удобно пользоваться как с компьютера, так и с телефона.

## 🛠️ Технологии

- Чистый **HTML5, CSS3, Vanilla JS**.
- **Canvas API** для рендеринга и применения фильтров.
- **@imgly/background-removal** (WebAssembly) для удаления фона.

## 📁 Структура проекта

Проект состоит всего из трех файлов:
- `index.html` — разметка интерфейса.
- `style.css` — стили (тёмная тема, адаптив).
- `script.js` — логика загрузки, фильтрации и удаления фона.

## 🖥️ Как запустить локально

1. Склонируй репозиторий или скачай файлы.
2. Просто открой `index.html` в любом современном браузере.
